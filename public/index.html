        Glossaire — comprendre les badges
        P1
        Exploitation confirmée, ou risque de compromission majeur (exécution de code sans authentification sur un composant exposé). À traiter en priorité, E-CAB si besoin.
        P2
        Exploitation possible seulement sous conditions (accès réseau interne, compte, privilèges). À planifier au CAB.
        CVE
        Identifiant public unique d'une vulnérabilité (ex. CVE-2026-123890).
        CVSS
        Note de gravité de 0 à 10, calculée sur la faille elle-même ; 9 et plus = critique. Ne dit pas si elle est exploitée.
        KEV
        Catalogue de la CISA (agence cyber américaine) des failles dont l'exploitation réelle est prouvée. Le meilleur signal d'urgence.
        Échéance KEV
        Date limite imposée aux agences fédérales US pour corriger. Nous l'utilisons comme repère, pas comme obligation.
        EPSS
        Probabilité (FIRST) qu'une faille soit exploitée dans les 30 prochains jours.
        Zero-day
        Faille exploitée avant que l'éditeur ne publie un correctif.
        RCE
        Exécution de code à distance : l'attaquant fait tourner ce qu'il veut sur la machine.
        NV
        Non vérifié dans les sources consultées : l'information manque, elle n'est pas estimée.
